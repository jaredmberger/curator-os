# Protected Research Agent Intake — implementation pilot

This endpoint is **disabled by default**. It is not connected to the GitHub Actions workflow or the CuratorOS viewer yet.

`POST /api/research-agent/import`

Requires Cloudflare Pages environment variable `RESEARCH_AGENT_IMPORT_ENABLED=true` and a **secret** `RESEARCH_AGENT_IMPORT_TOKEN`. Send `Authorization: Bearer <secret>`, `Content-Type: application/json`, and a body of:

```json
{
  "run_id": "39156470158",
  "register": {
    "schema_version": 1,
    "guide": "ss-example.html",
    "claims": []
  }
}
```

The real `claims` array contains the structured register fields generated by the agent. An empty register is permitted, but creates no claim records.

The endpoint validates a bounded request body, guide identifier, enumerations, required claim fields, and source URL schemes. It enforces `unverified_pending_editorial_review` and `independently_verified=false`, rejecting attempts to supply other statuses. Claims are individually stored under content-addressed `research-agent/claim/v1/<sha256>` KV keys, independent of `/api/research-state`. Re-imports of the same normalized claim and URL use the same key. The record contains the full structured claim and source run ID. No public ship guides or canonical Ship Records are edited.

**Important limitations and production gates:**
- There is no automatic artifact upload, review-status mutation, dashboard list API, or permanent Markdown dossier archive yet.
- KV is eventually consistent; concurrent writes and cross-region duplicate detection are not transactionally guaranteed. No global index is maintained.
- A bearer secret does not replace verifying Cloudflare Access policies, deployment domain restrictions, and operational rate limits.
- Imported research is model-generated and **not independently verified**.
- `RESEARCH_AGENT_IMPORT_ENABLED` must remain unset (disabled) in production pending an explicit go-live decision, security review, backup integration, and full `npm run check` verification.
- Test locally using `node --test tests/research-agent-import.test.mjs`.

Never put `RESEARCH_AGENT_IMPORT_TOKEN` in a client-side page, repository file, URL query, workflow log, or publicly exposed environment variable.
